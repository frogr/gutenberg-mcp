Remote MCP server

Classic books your AI can read, search and quote correctly

MCP (Model Context Protocol) is the open standard that lets AI apps like Claude and Cursor call outside tools. This server connects them to Project Gutenberg, the free library of 75,000+ public-domain books. Your assistant can find a book, read it by chapter with line numbers, and check a quotation against the real text before it repeats it. No API key needed.
